# Pokédex · Laboratorio 09, ejercicio 1

Aplicación Android en Kotlin y Jetpack Compose que consulta [PokéAPI](https://pokeapi.co/docs/v2) para explorar Pokémon en español.

## Funciones

- Catálogo con búsqueda por nombre o número, filtros por generación, tipo y grupo huevo, y ordenamiento.
- Fichas con estadísticas, evoluciones, debilidades y resistencias, habilidades, movimientos y forma variocolor.
- Pokémon capturados y equipo de hasta seis integrantes, guardados en el dispositivo.
- Vista clara y oscura con selección persistente.

## Ejecutar

Abre el proyecto en Android Studio, sincroniza Gradle y ejecuta `app` en Android 7.0 (API 24) o superior. La consulta de datos e imágenes requiere Internet.
